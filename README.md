# Fenix Coin Exchange

Iremos iniciar agora um projeto do Ecoteiner, é uma aplicação para gerenciar uma instituição de reciclagem que troca produtos reciclados por "fenix coin" e que pode ser trocada por dinheiro nos pontos de coleta, em anexo tem um documento com funcionalidades e regras que o sistema precisa, e também imagens de como precisa ficar
