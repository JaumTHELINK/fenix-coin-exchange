# Ecoteiner — Fênix Coin Exchange

Plataforma de uma instituição de reciclagem: usuários entregam materiais recicláveis nos pontos de coleta, recebem **Fênix Coin (FC)** e resgatam produtos do sistema ou de lojas parceiras.
